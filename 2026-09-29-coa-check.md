## What was built

### Part 1: the function and the scorer (`645ef21c`)

**`api/coa.js`** is the site's one server function. It runs on Node with zero dependencies, using the Web `fetch` handler; Vercel compiled it from ESM without a package.json. In order:

1. **Method.** Anything but POST gets 405 with `Allow: POST`.
2. **Origin.** A foreign `Origin` header gets 403.
3. **Turnstile.** The token comes in an `x-turnstile-token` header, so it is verified before the body is read. It **fails closed**: no secret, Cloudflare unreachable, or a bad token all return 503/403.
4. **Pages.** 1–4 `page` parts, 4 MB in all. Each must be a JPEG, checked by its frame header, 1,568 px or less on its longest edge. A bad upload costs no check.
5. **Rate limit.** 10 checks per IP per sliding hour, in the instance's memory. IPs are kept as salted hashes. It **fails open** on a cold instance, returns 429 with `Retry-After` when hit, and runs after validation.
6. **Model.** Claude Haiku 4.5 (`claude-haiku-4-5-20251001`):
   - temperature 0, max_tokens 1,500;
   - base64 image blocks, each labelled "Page n:";
   - a fixed system prompt, cached with the tool definition (`cache_control: ephemeral`; 4,844 tokens, above Haiku 4.5's 4,096-token minimum, so caching engages).
7. **Record.** The model must call `record_coa`, whose input is the brief's flat, nullable 30 fields and nothing else.
   - Strict structured outputs can't hold 30 nullable fields: their limit is 16 union types, and each nullable field is one. So it's a forced, non-strict tool, and the function holds the answer to the schema.
   - Types are coerced, unknown keys dropped, strings capped, and "N/A" becomes null. A non-COA is emptied except `page_count_read` and `legibility_notes`.
8. **Logs and storage.** Only error statuses are logged: never a body, an image or an extracted value. Nothing is stored.

**`coa/scorer.js`** holds pure functions, shared by the page (`window.CoaScorer`) and the tests (`module.exports`), the same pattern as the calculator's math. Every word on the slip comes from here:

- **The six lines** (the brief's rules):

  | Line | Established | Partial | Not shown |
  |---|---|---|---|
  | Identity | both masses within ±2 Da | masses outside ±2 Da (flagged; never Not shown); or a method or result without both masses | no identity test |
  | Purity | a % with a named method | a % without a method (flagged), or a method without a % | neither |
  | Quantity | measured mg beside labeled mg | measured only | labeled only, or neither |
  | Safety tests | endotoxin, sterility and heavy metals all shown | some shown; each is listed separately | none shown |
  | Traceability | lab, report ID, batch, date and sign-off all present | the missing ones named | none present |
  | Verifiability | a report ID plus a known lab route | a report ID with an unknown lab, or a printed QR code or lookup address | none of these |

- **Things to look at.** At most three, neutral, in this order:
  1. the report names a different compound from the `?c=` page;
  2. the reading note;
  3. a report or test date after today;
  4. a mass gap over 2 Da;
  5. a blend whose quantities can't be compared;
  6. measured more than 10% off the label;
  7. purity without a method;
  8. test and report dates over 30 days apart;
  9. a test over a year old;
  10. no compound named;
  11. purity above 100%;
  12. no acceptance limits printed.
- **The lookup route.** Janoshik and Freedom Diagnostics are known, with their portals. Any other lab gets "Look up the report ID on the lab's own site: {lab}. Find the site yourself, not through a link from the seller." An address printed on the document is never a link.
- **"What this document cannot tell you"** uses the artboard's copy verbatim, under your heading.
- **The share card title** uses only the site's own compound names:
  - a blend the site knows is its stack ("GLOW Stack", and "CJC/Ipamorelin" becomes "GH Stack");
  - anything unmatched is "Peptide".

**Tests:** `tests/coa-scorer.test.mjs` (21 cases, including a scan of every string the scorer can produce for the four banned words) and `tests/coa-function.test.mjs` (11 cases, with Cloudflare and Anthropic mocked).

### Part 2: the page `/coa/` (`17fa0c6d`)

- **Title:** "Peptide COA Check — read any Certificate of Analysis | Kalios".
- **H1:** "What the paper shows" (spec §5), under the eyebrow "Peptide COA Check · any lab · free", with Karl beside it.
- **Above the fold on phones:**
  - the one-line explainer;
  - **Take a photo** (paper primary; `capture="environment"` opens the rear camera);
  - **Upload photo or PDF** (images and PDF, several at once);
  - your privacy sentence.

  On desktop the two inputs are equal weight, side by side in a drop zone.
- **One pipeline in the browser.**
  - Each page is drawn on a canvas, shrunk to 1,568 px on its longest edge and saved as a JPEG at 0.8. It steps down to 0.7, then 0.6, only to fit 4 MB, and refuses after that.
  - PDFs render with **pdf.js 6.3.289** from cdnjs (the current release). It is fetched with its sha384 hash, run from a blob URL, and loaded only when a PDF is chosen.
  - More than 4 pages is refused, not cut short.
- **States:**
  - pages staged as thumbnails, so you see exactly what will be sent, with add, remove and read;
  - processing, with thumbnails of the pages sent;
  - the slip;
  - errors in plain words:

    | Error | Next step |
    |---|---|
    | unreadable | retake in better light, whole page in frame |
    | not a COA | said plainly |
    | over the limit | PDF pages, size |
    | 10 an hour | "try again in a bit, about N minutes" |
    | the person check | try again |
    | timeout or service | try again (your pages are kept) |

- **The slip follows v11-COA:** six rows, each with its stamp, the finding, and one plain-English sentence on what the test means.
- **Verify on the lab's site** shows the report ID with a one-tap Copy (Task / Search code / Report ID) and, for a known lab, the portal button.
- Below the slip: things to look at, what this document cannot tell you, **Share this slip** and **Check another**.
- **Share.** A 1080 x 1350 PNG in the Street Lab design, with mark-solid top right and Karl bottom right. It carries the compound name (the site's own words), the six stamps, the date and page count, and `kalios.health/coa`. It never carries a lab, a report ID or a client.
  - Where the browser allows it, `navigator.share` sends the PNG, one line of text and the link.
  - Otherwise the PNG downloads and the link is copied.
  - The PNG is drawn before you tap, so the share stays inside the tap, as the calculator's does.
- **Below the tool:** "What a COA can and can't tell you" (270 words, documentation only), then "Reading a COA: four questions". Their FAQPage JSON-LD is identical to the visible text.
- **Fine print:** the site disclaimer, plus how it works:
  - page images only;
  - Anthropic reads them;
  - the stamps come from fixed rules in your browser;
  - Cloudflare Turnstile checks that a person is asking;
  - Kalios keeps nothing;
  - Anthropic's 30-day deletion.
- **Umami:** one event, `coa-check`, per completed check. It is a count with no properties.

### Part 4: the fixture runner and screenshots (`7a8db749`)

1. It prepares each file in `fixtures/` with the page's **own** pipeline in headless Chrome (pdf.js, canvas, 1,568 px, JPEG), so the tests send exactly what a browser sends.

## Cost math

**Haiku 4.5 prices** (Anthropic's pricing page, today), per million tokens:

| Kind | Price |
|---|---|
| Input | $1 |
| 5-minute cache write | $1.25 |
| Cache read | $0.10 |
| Output | $5 |

**Image tokens.** A page costs ⌈width/28⌉ × ⌈height/28⌉ visual tokens. Haiku 4.5 is on the standard tier: long edge 1,568 px, at most 1,568 visual tokens. A letter page at 1,109 x 1,568 px would be 40 x 56 = 2,240 tokens, so the API scales it to the cap: **about 1,568 tokens, or 0.16¢, per page**. The measured uncached input confirms it:

| Pages | Uncached input | Breakdown |
|---|---|---|
| 1 | 1,940 | 1,568 + 372 |
| 2 | 3,563 | 2 x 1,568 + 427 |
| 3 | 5,077 | 3 x 1,568 + 373 |

The 1,000 px phone photo costs fewer tokens: 1,452.

**The cached prompt.** The system prompt plus the tool definition come to **4,844 tokens**, measured from `usage`. That is above Haiku 4.5's 4,096-token minimum, so caching engages:
- a warm check reads them for 0.05¢;
- the first check in any 5-minute gap writes them for 0.61¢.

**Output** was 624–758 tokens per check (max_tokens 1,500 is headroom).

**The brief's example**, 2 pages + cached prompt + 800 output:

| Cache | Input | Cache read / write | Output | Total |
|---|---|---|---|---|
| Warm | 3,563 → 0.36¢ | read 4,844 → 0.05¢ | 800 → 0.40¢ | **0.81¢** |
| Cold | 0.36¢ | write → 0.61¢ | 0.40¢ | **1.36¢** |

"~1¢" holds.

| Case | Warm | Cold (first in 5 min) |
|---|---|---|
| 1 page, measured | 0.53–0.62¢ | 1.17¢ |
| 2 pages, measured | 0.77¢ | ~1.33¢ |
| 3 pages, measured | 0.92¢ | ~1.48¢ |
| 4 pages, 750 output (estimate) | ~1.10¢ | ~1.66¢ |
| 4 pages, all 1,500 output tokens used (never seen) | ~1.46¢ | **~2.03¢**, the only case over 2¢ |

**At low traffic** most checks pay the cache write. A 1-hour cache costs twice as much to write and pays off from about three checks an hour. That's worth revisiting once there's traffic data. Say if you want it.

**Your $25 cap** covers about 2,100 cold checks or 3,900 warm ones. Abuse is bounded by:
- Turnstile;
- 10 checks per IP per hour;
- the 4-page, 4 MB, 1,568 px limits;
- the cap itself.

**Vercel.** The function mostly waits on the model, so Active CPU is negligible.
