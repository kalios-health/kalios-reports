A refusal (401, 403, 429, a bot challenge, a block page) is reported as refused, never retried, and its host isn't asked again in the run. The cache lives in the state file: validators for conditional requests, the Archive's content digests, and what was read before (a press release is read once). Fetched text is data: the report counts anything in it that reads like an instruction.

## DECISIONS

Conservative throughout; no questions asked.

**Part 0**
- **D1. Only the K goes.** The title keeps the width it had beside the top-right mark, so no title draws differently; the mark stays where Karl stood.
- **D2. The rule recorded where the question stood** (CLAUDE.md, `data/routes.json`, the four allowlist reasons). The gate keeps the four findings, allowed: under the rule each is a truth item for its dosing section, queued behind WADA.

**Part 1**
- **D3. robots.txt for pages, published terms for APIs.** The scanner honors robots.txt on the pages it reads (fda.gov, WADA, the Archive). ClinicalTrials.gov's and NCBI's robots.txt keep crawlers off their API paths; the scanner isn't a crawler, it makes one documented query at a time, at most one a second, under each API's own terms. Honoring those lines instead would make sources (e) and (g) impossible, and the brief names them.
- **D4. fda.gov's 30 seconds are honored**, which makes a run about a quarter of an hour.
- **D5. WADA refuses, so the Archive stands in, declared.** WADA's firewall answers automated clients with a challenge (HTTP 202, even on robots.txt). The scanner reports it and doesn't work around it; it reads the Internet Archive's index of WADA's List files and the Archive's copies, and says so with each copy's capture date.
- **D6. The cache is the state file,** since the brief allows no other file: validators, digests and what was read. A URL is fetched once per run and nothing is retried.
- **D7. Press releases are read once each:** the feed's one-line descriptions name almost no compound. The report shows the name matched and the title, no snippet, because a release can name private people.
- **D8. The Federal Register query quotes every name,** and a document counts only where its title, abstract or excerpts name the compound: unquoted, a brand the search has never indexed turned the query into "compounding", which it stems, and an SEC rule "named" dulaglutide.
- **D9. Events only for FDA's own documents,** as the events file keeps WADA's lists, other agencies and companies out. `after` reads "To be read from the source" and `cited_on` is empty: a person writes both.
- **D10. The site's own names, filtered.** COA Check's name list (names, trade names, aliases) without descriptions, company names, codes too short to mean one thing, and two-residue sequences; acronyms match as written; where names overlap the longest wins ("Thymosin beta-4, fragment … also known as TB-500" is TB-500; "insulin-like growth factor" isn't insulin).
- **D11. The trials tracked** are the Pipeline rows' and every NCT number the in-scope pages cite (369); new registrations are searched without the registry's MeSH synonyms, or an enclomiphene search returns clomiphene's IVF trials.
- **D12. Labels: the makers' own** (`is_original_packager`), prescription only; application numbers asked in both NDA and BLA forms, since the data writes Trulicity's BLA as an NDA.
- **D13. A ★ only for a trial report in people whose title names the compound;** reviews, protocols, secondary analyses and animal studies get ☆ and no truth item. A stack's papers name every member.
- **D14. First-run comparisons only against the site's own data:** the 503A list against the version the data was read from (the same), the Category 2 table against the recorded categories (they agree), the Pipeline rows against the registry (two differ).
